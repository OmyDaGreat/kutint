= Kutint
:toc: preamble
:toclevels: 3
:source-highlighter: rouge
:icons: font

A Color extension utility library for https://kobweb.varabyte.com[Kobweb] & Compose HTML

== Installation

To use this library in your JS project, add the following dependency to your `libs.versions.toml` file:

[source,toml]
----
[versions]
kutint = "<latest version>"

[libraries]
kutint = { group = "xyz.malefic", name = "kutint", version.ref = "kutint" }
----

and to your `build.gradle.kts` file:

[source,kotlin]
----
sourceSets {
    jsMain.dependencies {
        implementation(libs.kutint)
    }
}
----

== Features

- Dynamic color manipulation and conversion, including between and around both RGB and HSL color spaces
- Decent Dokka documentation: https://omydagreat.github.io/kutint/
